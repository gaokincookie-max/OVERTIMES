# OVERTIME 業務試験室 v2.1
独立試作版。index.html を開いて試験できます。PC4業務の問題・件数・操作ルールは前版と同じです。
書類4業務はドラッグ追従、対象別ドロップ判定、12pxの判定余裕、収納・復帰アニメーション、押印、収納枚数表示を追加。音はWeb Audioによる簡易合成音で、ヘッダーから無効化できます。画像生成・外部依存なし。
- js/drag.js: ポインター操作・中断・アニメーション
- js/paper.js: 書類4業務
- js/sound.js: 作業音
- css/jobs.css: 外観・横画面調整
- js/config.js, generator.js, pc.js, main.js: 前版の仕様を保持
本体への統合・怪異・停電・保存との連携は未実装。実機タッチと音質は未確認。
