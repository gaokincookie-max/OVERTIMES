# 残業 / OVERTIME

統合試作 Ver.0.12.1。スマートフォン横画面向けの業務処理型サバイバルホラーです。3体同時活動モードを追加しました。

## 起動方法

ビルド・npm install は不要です。HTTP サーバーから `index.html` を開いてください。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` にアクセスします。Windows では `py -m http.server 8000` でも起動できます。HTML の直接ダブルクリックでは、ブラウザの file:// 同一オリジン制限により監視カメラ連携が失敗する場合があります。

## GitHub Pages

1. リポジトリを作成し、このフォルダの**中身すべて**をルートにアップロードする（index.html がルートに来るようにする）。
2. Settings → Pages → Build and deployment → Source を Deploy from a branch に設定。
3. main ブランチの / (root) を選択し保存する。
4. 公開URLは Pages の画面に表示される。

相対パスを使用しているため、プロジェクトサイトのサブパスでの公開を想定しています。公開リポジトリでは画像も閲覧可能になるため、公開前に素材の利用条件を確認してください。ライセンスは未指定のため追加していません。

## Ver.0.12：怪異統合

監視画面で「3体同時（統合）」を選択し「統合巡回開始」を押してください。個別モードは引き続き使用できます。

- `camera/js/occupancy.js`：地点の排他管理。
- `camera/js/multi.js`：独立巡回、入口の排他、配電盤の再出現。
- `camera/js/config.js` の `multiConfig`：暫定タイミング・隣接関係。
- 電気室は巡回社員・光反応型の画像がないため専用地点。
- 自席接近中は退去先の地点も予約する。退去後4秒は次の接近を開始しない。
- 統合停止は接近を解除して初期化する。

検証：`node tests/occupancy.test.cjs` と `node tests/multi.test.cjs`。ブラウザ実機検証は別途必要。

## Ver.0.12.1 — 監視カメラの電源連動

モニター消灯中・停電中は監視画面への移動を禁止。監視中に停電すると中央PCへ戻る。照明のみの消灯は監視を妨げない。AIは継続し、映像を見られない間は配電盤の監視時間に加算しない。復旧時は従来どおり停電前の電源状態に戻す。
